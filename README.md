One funny text message, as if sent by yourself from the future — under 200 characters, no setup, no context.

> Hey, it's you from 2036. Stop saving the good plates for guests — future you eats cereal off them every night and honestly? Living the dream. Also, the plant lives — and it has a name now. Gary.

## How it works

`main.py` writes that single text to `/output/entry.txt`.

```sh
python3 main.py
```
